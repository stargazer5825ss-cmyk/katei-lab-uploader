Privacy Policy

Effective date: 2026-11-08 (updated 2026-11-08: added comment posting)

1. Use of YouTube API Services

Katei Lab Uploader (“the tool”) uses YouTube API Services to upload videos to YouTube. By using the tool, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

2. Information the tool accesses, stores, and shares

  • Google sign-in (OAuth 2.0): the tool requests the youtube.upload and youtube.force-ssl scopes. It receives an OAuth token and stores it only on the user's own computer, in a file that only the user can read. The token is never sent anywhere except to Google.
  • Videos and their title, description, and tags: these are prepared by the user on their own computer and are sent only to YouTube, to upload the video to the user's own channel.
  • Video status and comments: the tool reads only the privacy status of the user's own uploaded videos, and posts one comment that the user wrote and approved on each of those videos after they are public. It does not read, change, or delete any other comments or videos.
  • Upload results: the tool keeps the ID and URL of each video the user uploaded, in a file on the user's own computer, so the user can find their own video later.
  • The tool does not read or store any other YouTube data, and it does not collect data about other people.
  • The tool has no server. It does not use cookies, analytics, advertising, or device tracking, and it does not sell or share any information with third parties.

3. How to revoke access and delete data

  • You can revoke the tool's access to your Google account at any time from the Google security settings page: https://security.google.com/settings/security/permissions.
  • To delete the stored token, delete the file ~/.config/katei-lab-shorts/youtube-token.json on your computer.
  • To delete stored upload results, delete the publish.json files in the tool's folder.
  • Videos on YouTube can be deleted in YouTube Studio.

4. Changes and contact

We will update this page if the way the tool handles data changes. Questions: GitHub Issues

プライバシーポリシー（日本語）

1. YouTube API サービスの利用

Katei Lab Uploader（この道具）は、動画を YouTube にアップロードするために YouTube API サービスを使います。 この道具を使うと、YouTube 利用規約に同意したことになります。 Google によるデータの扱いは Google プライバシー ポリシーのとおりです。

2. 触れる情報・保存する情報・共有する情報

  • Google のログイン（OAuth 2.0）：権限は youtube.upload と youtube.force-ssl です。受け取ったトークンは利用者のパソコンの中にだけ、本人だけが読めるファイルとして保存し、Google 以外には送りません。
  • 動画とタイトル・説明文・タグ：利用者が自分のパソコンで用意したもので、自分のチャンネルへのアップロードのために YouTube にだけ送ります。
  • 動画の状態とコメント：自分が上げた動画の公開状態だけを読み、公開されたあとで、利用者が書いて OK を出したコメントを1つ書き込みます。ほかのコメントや動画は読まず、変えず、消しません。
  • アップロードの結果：自分が上げた動画の ID と URL を、利用者のパソコンの中のファイルに残します。
  • ほかの YouTube のデータは読まず、保存もしません。ほかの人のデータも集めません。
  • サーバーはありません。Cookie・アクセス解析・広告・端末の追跡は使わず、情報を第三者に売ったり渡したりしません。

3. 許可の取り消しとデータの削除

  • Google アカウントへの許可は、Google のセキュリティ設定のページでいつでも取り消せます。
  • 保存したトークンは、パソコンの ~/.config/katei-lab-shorts/youtube-token.json を消すと削除できます。
  • アップロードの結果は、道具のフォルダの publish.json を消すと削除できます。YouTube の動画は YouTube Studio で削除できます。

4. 変更と連絡先

データの扱いが変わるときは、このページを更新します。問い合わせ：GitHub Issues
